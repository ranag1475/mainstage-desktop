## 🧰 What Mainstage Desktop Does

Mainstage Desktop focuses on one job and does it well: protecting the folders that hold your Mainstage presets and samples.

- **Dated copies before every patch.** Each time you start a patch, the utility makes a copy of your preset and sample files and labels it with the date and time. If something goes wrong later, you can go back to the exact version you had before.
- **Folder-level snapshots.** Point it at a project folder once, and it remembers. You do not have to re-select folders every session.
- **Preset and sample coverage.** Both file types are included, so a patch never leaves one half of your project unprotected.
- **Plain folders on your own disk.** Copies are stored as ordinary folders you can open in File Explorer at any time. Nothing is hidden or locked away in a proprietary format.
- **Quiet background operation.** Once configured, the tool stays out of your way and works in the background while you focus on your project.
- **Simple list view.** See every snapshot that exists, when it was created, and how much space it uses.
- **One-click cleanup.** Remove old snapshots you no longer need, individually or by age, to keep your drive from filling up.
- **Portable-friendly design.** The application can run from a folder you choose, including a USB drive, so your setup travels with you.

## 🗂️ How the Backup Process Works

Understanding the flow takes about thirty seconds and makes everything else obvious.

1. You choose a Mainstage project folder using the built-in folder picker.
2. Mainstage Desktop reads the preset and sample files inside that folder.
3. It creates a new dated folder, for example a name ending in the current date and time.
4. Your preset and sample files are copied into that dated folder.
5. The original files stay exactly where they were, untouched.
6. When you start another patch later, a new dated folder is created, and the previous one remains available.

Because every snapshot is a separate dated folder, you always have a clear timeline of your project. If a patch goes wrong, you simply open the snapshot from before the change and copy your files back.

## 🧭 Everyday Use

The main window is arranged around a short list of folders and a list of snapshots.

- **Add a folder:** Use the Add Folder button and pick your Mainstage project folder.
- **Take a snapshot now:** Press the Snapshot button at any time for an immediate dated copy.
- **Restore files:** Open the dated snapshot folder in File Explorer and copy the files you need back into your project folder.
- **Remove a snapshot:** Select it in the list and choose Delete. This removes only the copy, never your originals.
- **Review space usage:** The status area shows how much room your snapshots take, so nothing sneaks up on you.

There is no wrong button to press. Deleting a snapshot never touches your live project files, and taking a snapshot never changes them.
